# Treino de Lógica

Repositório estruturado por pacotes para prática de algoritmos e lógica de programação em Java, com soluções complementares em JavaScript e Python.

## Progresso por Tema

| Pacote | Foco |
| :--- | :--- |
| **basico** | Fundamentos: laços, condicionais e acumuladores. |
| **strings** | Manipulação de texto e transformações. |
| **arrays** | Vetores, buscas e manipulação de elementos. |
| **contagem** | Frequência com `HashMap` e `HashSet`. |
| **matrizes** | Laços aninhados e padrões geométricos. |
| **ordenacao** | Algoritmos manuais e buscas eficientes. |
| **recursao** | Funções autorreferenciais e pilhas. |
| **matematica** | Teoria dos números e conversões. |
